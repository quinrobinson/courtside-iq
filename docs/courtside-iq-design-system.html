Principles

01

Five rules that govern every design decision. When two rules conflict, development-first messaging wins.

1

Development-first, always

Numbers earn their place by connecting to growth. Never surface a stat without a development frame around it. A 76% PPSA is not data — it's a "Solid scoring efficiency for a 14-year-old guard."

2

Tight, modular spacing

The signature of Courtside IQ's look is dense, deliberate spacing. Cards sit 8px apart, never 16. Inner padding is 16–20px. Generous gaps signal default Material; we are not Material.

3

Hairlines over shadows

Every card carries a 1px hairline. Shadows are reserved for elements that genuinely float (modals, sheets, the tab bar). Drop shadows on every card create visual noise.

4

One hero color, four accents

Jade is the dominant brand presence — actions, default fills, anywhere a screen needs life. Royal, Steel, Rose, and Spark are moments, used once per screen at most. The references work because they pick a single color personality per screen. We do the same.

5

Nested radius rule

A child element's corner radius is always 2–4px smaller than its parent. A 6px card contains 4px sub-pills, which contain 2px chips. Tighter scale, same architectural principle.

6

Tier hierarchy stays consistent

Solid → Good → Elite, plus Room to Grow. Solid is entry-level, never negative. Removing one tier from any metric requires removing it from all. Color tokens for tiers are global.

Color

02

One hero color, four accents. Jade is the dominant brand presence — actions, default chart fills, brand mark, "Solid" tier. The other four brand colors (Royal, Steel, Rose, Spark) are reserved for moments: AI blocks, growth edges, peak performances. Each accent gets one job and one job only. The references work because they pick a single color personality per screen — ours does the same.

Hero color usage

Jade can appear anywhere. It's the default for primary buttons, brand mark, default trend-up indicator, default chart fill, "Solid" tier, and any neutral affordance. If a screen needs color and the meaning is just "alive," use Jade.

Accent color limits

Accents appear once per screen, max. One Royal block (the AI insight). One Spark moment (when something is genuinely Elite). Rose is for growth-edge framing, applied with restraint. Steel is the backup color when Jade is already used elsewhere on the same chart.

Hierarchy rules

One climb per screen

A screen with two Tier 2+ cards starts to feel decorated. Pick the most important moment and elevate it; the rest stay default. The Hero tier especially: one per screen, often zero.

Tier follows meaning, not preference

Don't pick a tier because the card "needs" pop. Pick it because the moment justifies the volume. A Royal Glow on a routine stat reads as inflation — and dilutes the tier when it's actually needed.

Hero is not a Royal card

Tier 5 looks like Royal but it isn't an "AI moment" — it's a feature-level headline. The Royal is providing weight, not meaning. Use it for things like the development snapshot, season summary, or onboarding hero.

Glows don't change card structure

Same 6px radius, same 16–20px padding, same hairline (or shadow on Hero). Glow cards are the regular card with a treatment, not a different component. A Tier 2 card next to a Tier 1 card should still feel like the same family.

Why 8px gaps

Cards sit 8px apart vertically. Material defaults to 16–24, which makes a dashboard feel like a settings screen. The tighter gap is what reads as "designed."

Stat row, not stat cards

Two metrics that should be compared share a single card with a 1px hairline divider. Not two separate cards. Comparison is the meaning, the container should reflect it.

One Royal block per screen

Royal (purple) signals AI. One block per screen, max. Two starts to feel like a feature dump and dilutes the meaning.

Tier tag = card temperature

A tier pill in the corner of a card colors the read of everything inside it. Use sparingly — only when the card is summarizing a single rated performance.

Floating tab bar

Pill tab bar floats on Ink, not Canvas. The shadow is real here — it's the only thing on screen that genuinely floats, so the elev/pop shadow earns its place.

Figma setup

11

Token names in this doc map 1:1 to Figma Variables. Create one collection per category, then use them across components and styles. Recommended order below.

Collections to create
  1. color/brand · jade, royal, steel, rose, spark (50–700 stops)
  2. color/surface · canvas, canvas-sunk, surface, surface-alt, hairline
  3. color/text · ink, ink-2, ink-3, ink-4, ink-onbrand
  4. radius · xs, sm, md, lg, xl, full
  5. space · 1, 2, 3, 4, 5, 6, 8, 10, 12
  6. elevation · hairline, card, pop, modal (effect styles)
  7. type · 10 text styles (display lg/md/sm, h1, h2, h3, body, small, caption, eyebrow)
Components to build (in order)
  1. Card · base + tight/standard/roomy + 4 standout variants (Jade/Royal/Spark/Hero)
  2. Tier tag · solid/good/elite/grow/ai/muted
  3. Metric tile · with/without tier dot, with/without trend
  4. Button · primary/secondary/ghost · sm/md/icon · (AI variant held in reserve)
  5. Player header · with/without action
  6. AI insight block · single variant
  7. Tab bar · 4-tab pill, floating
FlutterFlow handoff

Once tokens are locked in Figma, mirror them in your FlutterFlow theme: App Properties → Theme Settings → Custom Colors. Use the same names (colorJade500, colorInk) so design and code stay aligned.

Spacing and radius can't be FF theme tokens directly, so create app_constants.dart in lib/courtside_iq/ with const doubles for each value. Reference from custom widgets.
